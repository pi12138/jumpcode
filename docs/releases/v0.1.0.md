# v0.1.0 发布说明

[项目首页](../../README.md) · [使用指南](../usage.md) · [开发指南](../development.md) · [English](v0.1.0.en.md)

首个正式版本。支持从 Linux 终端请求 Windows 桌面上的 VS Code 打开远程项目，也支持在 Windows 直接打开本地和 SSH 项目。

## 相比 v0.1.0-beta.1 的改进

- 修复 Linux 执行 `jc pair list` 被 Windows 平台检查拦截的问题。Windows 列出已签发的配对，Linux 显示本机保存的服务端地址和证书指纹。
- 配对命令误用平台时，准确提示具体命令应在 Windows 服务端还是 Linux 客户端执行。
- `pair list/status` 在未配对时显示“暂无配对凭据”；损坏或不完整的配置仍会报错。输出不显示密钥或密钥哈希。
- `jc client` 和 `jc pair join` 的整个 HTTP 请求默认超时从 30 秒缩短为 10 秒，TCP 连接和 TLS 握手各有 3 秒时限。
- 新增 `--timeout` 设置单次请求总超时，例如 `jc c . --timeout 5s`；拒绝零和负值，超时不会覆盖已有配对。
- 补充完整 CLI 命令、慢响应和 TLS 握手停滞的回归测试，以及双语使用说明。

## 主要功能

- Linux 中运行 `jc client .`，请求 Windows VS Code 通过 Remote-SSH 打开当前目录。
- Windows 直接打开本地目录、`主机:/目录` 和 `主机:~/目录`。
- `jc pair create/list/revoke/join/status` 管理凭据，每条凭据绑定固定 SSH 主机，支持独立撤销。
- TLS 1.3、证书指纹固定和服务端密钥哈希存储。
- 多 IPv4 监听，默认 `auto` 选择已启用网卡上的私有 IPv4。
- Windows 后台运行、状态查询、停止和用户登录后自动启动；后台日志记录生命周期及打开请求，隐藏项目路径和密钥。
- 中英文界面、短子命令和版本信息查询。

## 安装与升级

提供 Windows amd64 ZIP、Linux amd64 tar.gz、`release.json` 和 `SHA256SUMS`。压缩包包含对应程序、双语指南和此发布说明。安装方法见项目首页。

从测试版升级时可保留现有配对配置，无需重新配对。Windows 替换程序前先运行 `jc server stop`，保留原可执行文件路径以便现有登录启动任务继续使用；替换后可运行 `jc server --daemon` 立即启动。

## 验证范围与已知限制

- 发布流程执行 Windows/Linux 格式检查、`go vet`、测试和构建，Linux 额外执行竞态检查，并验证发布包校验和及 Linux 命令。自动检查不覆盖实际 Windows 桌面窗口和用户登录交互。
- 服务端只支持 Windows，客户端只支持 Linux；尚无公网中转和 IPv6 支持。
- 配对配置尚无跨进程锁，请顺序执行创建和撤销操作。
- Windows 直接打开 `主机:~/目录` 时的 SSH 主目录查询尚无程序级超时；此次请求超时调整不影响该过程。
- 自动监听地址在启动时枚举，网卡地址变化后需重启服务；客户端保存的服务端地址变化后需重新配对。
- `pair list/status` 只读取本地记录，不验证服务在线或凭据是否已撤销；撤销需在 Windows 执行。
- 日志追加写入，尚无自动轮转。VS Code 的最终连接结果以窗口中的提示为准。
