# v0.1.0-beta.1 发布说明

[项目首页](../../README.md) · [使用指南](../usage.md) · [开发指南](../development.md) · [English](v0.1.0-beta.1.en.md)

首个公开测试版本。Windows 桌面上的 VS Code 打开、登录启动等交互流程仍需结合实际环境验收；带 `.snapshot` 的产物为开发快照。

## 功能

- 在 Linux 中运行 `jc client .`，请求 Windows 上的 VS Code 通过 Remote-SSH 打开当前项目。
- Windows 支持直接打开本地目录和 `主机:/目录` 或 `主机:~/目录`。
- `jc pair create/list/revoke/join/status` 管理配对，每条凭据绑定固定 SSH 主机，支持单独撤销。
- HTTPS 使用 TLS 1.3 和固定证书指纹，服务端只保存配对密钥哈希。
- 支持多个 IPv4 监听地址，默认 `auto` 自动选择已启用网卡上的私有 IPv4。
- Windows 支持后台运行、状态查询、停止和用户登录后自动启动。
- 两种后台模式统一记录生命周期和打开请求日志，移除日志中的项目路径。
- 提供中英文 CLI、短子命令和 `jc --version`（`-v`）。

## 发布产物

Windows amd64 ZIP 和 Linux amd64 tar.gz 均附带双语指南、此发布说明及 `release.json`。外部 `SHA256SUMS` 校验两个压缩包和版本清单。

解压后将 `jc.exe` 或 `jc` 放到固定目录并加入 `PATH`。已安装登录启动任务时，替换程序前先停止服务，并保留安装任务时使用的可执行文件路径。

## 已知限制

- 服务端只支持 Windows，客户端只支持 Linux；公网中转和 IPv6 尚未提供。
- 配对配置尚未加跨进程锁，请逐条执行创建和撤销操作，避免并发修改。
- Windows 直接打开 `主机:~/目录` 时，SSH 主目录查询尚无程序级超时。
- 自动监听地址在启动时枚举；网卡地址变化后需重启服务，客户端地址变化后需重新配对。
- 日志追加写入，尚无自动轮转。VS Code 最终连接结果以窗口中的提示为准。
- 最新发布产物尚未完成 Windows 桌面交互的真机验收，CI 中的 Windows 测试不覆盖 VS Code 窗口和实际用户登录。
